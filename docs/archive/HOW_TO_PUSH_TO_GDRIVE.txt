                   HOW TO PUSH FILES TO GOOGLE DRIVE
                          STEM VCS Quick Guide

YOU HAVE TWO CHOICES
--------------------

The user correctly pointed out: "what's the point of VCS if it doesn't actually 
upload to Google Drive?"

You're absolutely right! Here are TWO ways to get real Google Drive backup:


===============================================================
OPTION 1: GOOGLE DRIVE DESKTOP APP (5 MINUTES - EASIEST!)
===============================================================

This is the FASTEST and EASIEST way:

STEP 1: Download and Install
-----------------------------
Go to: https://www.google.com/drive/download/
Install Google Drive for Desktop
Sign in with your Google account

STEP 2: Move Your Project
--------------------------
Move your project folder INTO the Google Drive folder:

Example:
  From: E:\STEM_VCS\previous_Versions\version_0
  To:   C:\Users\YourName\Google Drive\XylusOS_version_0

STEP 3: Use STEM Normally
--------------------------
cd "C:\Users\YourName\Google Drive\XylusOS_version_0"
stem init
stem add .
stem commit -m "Initial commit"

DONE! Files automatically sync to Google Drive!

Every time you commit, Google Drive Desktop will upload the changes.

PROS: Easy, automatic, works immediately
CONS: Uses local disk space


===============================================================
OPTION 2: DIRECT API UPLOAD (60 MINUTES - ADVANCED)
===============================================================

This integrates Google Drive upload into the 'stem push' command.

REQUIRES: Google Cloud Console setup (one-time, takes 30-60 minutes)

STEP 1: Create Google Cloud Project
------------------------------------
1. Go to: https://console.cloud.google.com/
2. Click "New Project"
3. Name: "STEM VCS"
4. Click "Create"

STEP 2: Enable Google Drive API
--------------------------------
1. In your project, go to "APIs & Services" > "Library"
2. Search for "Google Drive API"
3. Click "Enable"

STEP 3: Create OAuth Credentials
---------------------------------
1. Go to "APIs & Services" > "Credentials"
2. Click "Create Credentials" > "OAuth client ID"
3. Configure consent screen (if prompted):
   - User Type: External
   - App name: STEM VCS
   - Add your email
   - Scopes: Add ../auth/drive.file
   - Test users: Add your Gmail
4. Create OAuth client ID:
   - Type: Desktop app
   - Name: STEM Desktop
5. Download the JSON file

STEP 4: Configure STEM
-----------------------
1. Open the credentials JSON you downloaded
2. Find: client_id and client_secret
3. Open: C:\path\to\STEM_VCS\gdrive_upload.ps1 in a text editor
4. Replace these lines:
   
   $ClientId = "YOUR_CLIENT_ID.apps.googleusercontent.com"
   $ClientSecret = "YOUR_CLIENT_SECRET"
   
   With your actual values from the JSON file

5. Save the file

STEP 5: Authorize STEM
-----------------------
Run:
  cd C:\path\to\STEM_VCS
  powershell -ExecutionPolicy Bypass -File gdrive_upload.ps1 -SetupAuth

This will:
- Open your browser
- Ask you to sign in to Google
- Show authorization screen
- Give you a code to enter
- Save the authorization

STEP 6: Test Upload
--------------------
cd E:\STEM_VCS\previous_Versions\version_0
stem init --cloud "https://drive.google.com/drive/folders/YOUR_FOLDER_ID"
stem add .
stem commit -m "Initial commit"
stem push

This will upload all files to Google Drive!

PROS: Integrated into 'stem push', explicit control
CONS: Complex setup, requires Google Cloud Console


===============================================================
WHICH ONE SHOULD I CHOOSE?
===============================================================

CHOOSE OPTION 1 IF:
  - You want it working in 5 minutes
  - You don't want to deal with Google Cloud Console
  - Automatic syncing is fine
  - You have disk space

CHOOSE OPTION 2 IF:
  - You want 'stem push' to upload directly
  - You need explicit control over uploads
  - You don't want Google Drive Desktop installed
  - You're comfortable with technical setup
